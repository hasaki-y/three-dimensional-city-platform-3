# 0 阶段：现状基线（2026-10-09）

本文记录改造前的代码事实。数据是固定随机种子生成的**教学模拟数据**，不是杭州的真实建筑或 POI 测绘成果；坐标只是放在杭州未来科技城附近。生成器见 `server/scripts/generate-data.js`，本仓库数据可用于学习演示，不能据此做现实规划或应急决策。

## 启动和目录

- 根目录 `npm run dev` 同时启动 Express（3001）和 Vite（5173），前端 `/api` 由 Vite 代理到后端。
- `server/src/index.js` 是原有 HTTP 入口；`server/src/spatial.js` 在进程启动时将 GeoJSON 全量读入内存，并使用 Turf 计算。
- `web/src/App.vue` 负责三栏布局；`CityScene.vue` 创建 Cesium Viewer；`ControlPanel.vue` 提供筛选和分析入口；`StatisticsPanel.vue` 画图表；`FeatureInfo.vue` 展示拾取的建筑。
- 改造前**没有数据库进程或 PostGIS 查询**。依赖安装分别为根目录、`server`、`web` 的 `npm install`。

## 输入数据

| 文件 | 数量 | 几何 | 关键属性 |
| --- | ---: | --- | --- |
| `buildings.geojson` | 3489 | Point | id、name、type、district、floors、height、area、year、lon、lat |
| `pois.geojson` | 670 | Point | id、name、type、district、lon、lat |
| `roads.geojson` | 10 | LineString | id、name、type、coords |
| `districts.geojson` | 5 | Polygon | id、name、type、coords |
| `water.geojson` | 3 | Polygon | id、name、type、coords |
| `parks.geojson` | 3 | Polygon | id、name、type、coords |

GeoJSON 坐标顺序为 `[经度, 纬度]`，按 WGS84/EPSG:4326 使用；源文件未包含独立 CRS 声明。建筑数据只有**中心点**，没有建筑轮廓：Cesium 中的 30m×30m 盒子是视觉符号，`area` 是模拟业务字段，并非盒子底面积。缓冲区命中的是建筑**中心点**，不能解释为建筑轮廓与缓冲区相交。道路、水系、片区、公园也由脚本生成。

## 原有功能数据流

| 功能 | 输入与处理 | 输出与界面 |
| --- | --- | --- |
| 建筑渲染 | `GET /api/buildings` 从内存 GeoJSON 筛选并返回属性 | `CityScene.loadBuildings` 一次请求全部符合条件的建筑，逐栋建立 Cesium Entity Box；2D 改显示 Point |
| 建筑筛选 | 类型、最低楼层发给上述接口 | 原实现每次清空 `viewer.entities` 并重建建筑，同时清掉分析结果 |
| 建筑拾取 | `ScreenSpaceEventHandler` 左键 → `scene.pick` → Entity id | 查 `buildingMap` 中的属性，Pinia 存选中对象，右栏显示 |
| 缓冲区 | 地图点位 → `GET /api/buffer` → Node/Turf `buffer`、`pointsWithinPolygon` | 地图椭圆和统计结果；退出时清理 Entity、失效异步响应 |
| 最近邻 | 地图点位 → `GET /api/nearest` → Node/Turf `nearestPoint` 循环 | 地图连线、医院点位和结果；退出时清理 |
| 城市统计 | `GET /api/aggregate` 在内存中分组 | ECharts 类型饼图、高度段柱图；原实现未与建筑筛选联动 |

原接口还包括 `GET /api/overview` 和 `GET /api/health`。原前端只渲染建筑与分析覆盖物，未渲染 POI、道路、水系；没有 POI 聚合、视野 BBOX 请求、3D Tiles、地形剖面。3489 是对象数量，**没有万级性能实测结论**。

## 可复现演示与待测量项

执行三个目录的依赖安装后运行 `npm run dev`，打开 `http://localhost:5173`。检查建筑、2D/3D 切换、筛选、拾取、缓冲区退出、最近邻退出；拍摄主场景、分析结果、退出清理和错误状态截图。

性能基线目前**尚未测量**。后续在固定浏览器、设备和视角下分别记录 API 时长、网络传输、Cesium 建实体耗时、首屏可操作时间和地图交互体验；不可将单次主观流畅感写成性能指标。
